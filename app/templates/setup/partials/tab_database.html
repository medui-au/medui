Best Practice connection{{ help('setup.database') }}

Set BPSDB_HOST, BPSDB_DATABASE, BPSDB_USER and BPSDB_PASSWORD in your installation's .env file, then restart MedUI. Use the read-only account BP supplies for database access; MedUI checks below that it can't change Best Practice data.

If the server uses a private certificate, install its CA certificate on the MedUI host. BPSDB_TRUST_SERVER_CERTIFICATE is available for installations that require it.

MedUI's own PostgreSQL database is separate from Best Practice. Configure it with DATABASE_URL.
