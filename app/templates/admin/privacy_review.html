Privacy Review{{ help('privacy-review.overview') }}

Before a request goes to a cloud AI, MedUI checks the text it is about to send for anything identifying that redaction missed: the patient's own details, a practice contact's name or details, or something shaped like a phone number, address or Medicare number. This page lists the requests where that check found something, and those a user reported from the Sent to AI tab. Open a request to see each finding in context, add it to future redactions if it should be removed, and record what it was. Requests where the check found nothing are not listed.

How to read this list
Tier 0
{{ tier_labels[0] | capitalize }}: a name, date of birth, address, phone or Medicare number from this patient's own record. MedUI stops the request so the user can review it before anything is sent.
Tier 1
{{ tier_labels[1] | capitalize }}: a practitioner from the address book, a practice user, or the practice's own details. Also stops the request for review.
Tier 2
{{ tier_labels[2] | capitalize }}: the shape of a phone number, email, address, Medicare number or a titled name (Dr, Mrs…), which may belong to anyone. Recorded, not stopped. Many are harmless.
Outcome
Sent: the request went to the AI. Stopped at review: MedUI paused it and the user cancelled, or the pause timed out, so nothing was sent. Cancelled or Failed: it ended for another reason.
Review
What the reviewer decided: Real leak (it identifies someone and got through, or would have), False alarm (not identifying), or Acceptable (identifying, but appropriate here).
