# Contributing to MedUI

**For:** anyone who would like to help with MedUI. **You'll know:** what we welcome now, and why
code contributions wait.

## What we welcome now

- **Questions and ideas** in [Discussions](https://github.com/medui-au/medui/discussions).
- **Something that isn't working, a doc that's wrong, or a suggestion:**
  [open an issue](https://github.com/medui-au/medui/issues/new/choose) and pick the form that
  fits.
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) explains. Never in a
  public issue.

Reports from installing and running MedUI in a practice are the most useful help there is. See
[getting help](docs/support.md) for what to include.

## Code contributions: not yet

We are not accepting pull requests for now, and will close any we receive with a note pointing
here. If you would like to contribute code, start a discussion first and describe what you have
in mind.

Why: before we can accept code, each contributor will need to sign a short contributor agreement,
so that the project can keep the option of licensing MedUI on other terms as well as the GNU AGPL
v3. That agreement isn't in place yet. When it is, this page will say how to sign it and how to
send a change.

Changing MedUI for your own practice doesn't need any of this: the
[licence](LICENSE) lets you, and the README says what to keep
([If you change MedUI](README.md#if-you-change-medui)).

## Always

- **No patient details** in a discussion, issue, screenshot or log: describe the shape of the
  problem, or make up an example ([getting help](docs/support.md)).
- Keep to MedUI's [intended purpose](docs/intended_purpose.md). Ideas that would have MedUI
  diagnose, recommend treatment or investigations, triage or monitor patients are outside it.
