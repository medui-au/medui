# Getting help

**For:** anyone using or running MedUI who is stuck. **You'll know:** where to look first, and
how to ask without exposing patient data.

## First

1. **The help in the app:** the **?** beside each screen opens its own help.
2. **[Troubleshooting](troubleshooting.md):** common problems and the commands to diagnose them.
3. **`./medui.sh`** in the installation's folder: **Status** shows what is running, and
   **Support** prints a summary to copy into a question (version, system, what is running; no
   patient data or secrets).

## Asking

MedUI is pre-release, and support is limited.

- **A question** (how to install, set up or use MedUI): ask in
  [Discussions](https://github.com/medui-au/medui/discussions), where other practices can
  answer too.
- **Something that isn't working, or a doc that's wrong:**
  [open an issue](https://github.com/medui-au/medui/issues/new/choose) and pick the form that
  fits.

Both are public. When you ask, include:

- the MedUI version (at the foot of every page);
- Windows (WSL2) or Ubuntu, and live or demo;
- what you did, what you expected, and what happened, with any error message.

**Never send patient details**, passwords, API keys or `.env`, in a question, an issue, a
screenshot or an AI tool. Describe the shape of the problem instead ("a phone number written with
two spaces between its groups"), or make up an example.

A security problem goes privately: see [SECURITY.md](../SECURITY.md). Wanting to help: see
[contributing](../CONTRIBUTING.md).
